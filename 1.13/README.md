## Starting point

This is the earliest version in the repository. The pack is split into `post/` (post-processing effect chains, i.e. the old "Super Secret Settings") and `program/` (the individual GLSL programs those chains reference). At this point Minecraft has no user-overridable world rendering shaders, only screen effects.
